# LocalHub — AI 활용 지역 관광 정보 서비스

> **SSAFY에서 제작한 Vue 3 기반 지역 관광 웹 프로젝트**  
> 대전·충청 관광 정보를 지도와 콘텐츠로 탐색하고, 생성형 AI 챗봇을 통해 여행 정보를 질의할 수 있도록 구현했습니다.

## 한눈에 보기

- **지역 관광 탐색**: 한국관광공사 Tour API 기반 데이터로 관광지·콘텐츠 탐색
- **지도 시각화**: Leaflet을 활용한 관광지 위치 표시
- **AI 챗봇**: OpenAI API를 연동한 플로팅 여행정보 챗봇
- **커뮤니티**: 게시글 작성·수정·삭제·검색·북마크
- **반응형 UI**: 모바일 환경을 고려한 SPA
- **기술 스택**: Vue 3 · Vite · Vue Router · Leaflet · OpenAI API · localStorage · Netlify

## AI를 어떻게 활용했나

이 프로젝트에서는 AI를 두 가지 방식으로 활용했습니다.

### 1. 서비스 기능으로서의 AI
관광 정보를 탐색하다 바로 질문할 수 있도록 **OpenAI API 기반 챗봇**을 서비스 안에 결합했습니다.  
API 키가 없는 환경에서도 기본 관광 데이터와 게시글 키워드를 활용한 로컬 응답이 가능하도록 fallback 구조를 두었습니다.

### 2. 개발 과정에서의 AI 협업
Figma/기획 요구사항을 실제 Vue 컴포넌트와 화면 구조로 옮기는 과정에서 생성형 AI를 활용해 구현안을 빠르게 만들고, 직접 실행·검증하면서 UI와 로직을 반복 수정했습니다.

단순히 코드를 생성하는 데 그치지 않고 **요구사항 → 구현 → 실행 → 오류 확인 → 수정**의 반복 과정에 AI를 활용한 경험입니다.

## 주요 구현

| 영역 | 구현 내용 |
|---|---|
| Frontend | Vue 3 + Vite 기반 SPA |
| 관광 데이터 | 한국관광공사 Tour API 기반 제공 JSON |
| 지도 | Leaflet 관광지 핀 시각화 |
| AI | OpenAI API 기반 여행정보 챗봇 |
| 커뮤니티 | 게시판 CRUD, 검색, 조회수, 북마크 |
| 상태 저장 | localStorage 기반 교육용 구조 |
| 배포 | Netlify SPA 배포 설정 |

## 프로젝트에서 배운 점

생성형 AI를 활용하면 구현 속도를 크게 높일 수 있었지만, 결과를 그대로 사용하는 것보다 **요구사항과 실제 동작을 직접 비교하고 검증하는 과정**이 중요했습니다.

또한 프론트엔드에서 API를 직접 호출하는 교육용 구조를 구현하면서 API Key 노출과 CORS 같은 실제 서비스의 제약도 확인했습니다. 이후에는 AI가 만들어 준 결과를 빠르게 적용하는 것뿐 아니라, **보안·데이터 출처·실행 환경까지 함께 검토하는 방식**으로 개발하고 있습니다.
